가동률 화면 시안 비교 (SCR-003 개편)

목적: 타임라인을 보며 라인별 가동률을 비교하는 화면. 다섯 시안은 같은 데모 장면(2026-11-19 14:20, B라인 프레스 3단 고장 진행 중)과 같은 색 규칙을 쓰고, 비교하는 방식만 다르다. 각 화면은 1920×940 기준을 줄여 보였다 — "열기"로 실제 크기를 본다.

공통 규칙 · 타임라인은 이상만 색 (가동 = 옅은 회색, 대기 노랑 · 고장 빨강 · 통신 끊김 보라, 계획정지 = 회색 빗금이며 가동률 계산에서 뺌) · 진행 중 사건은 먹색 테두리 · 핵심 숫자는 화면에 하나 · 명세 항목(조회 조건, OEE + 3요소, 라인별 OEE, 비가동 코드별, 상태 타임라인)은 모두 들어 있음 · 주·월 선택 시 일별 추이는 이번 시안에서 그리지 않음 · 값은 데모
