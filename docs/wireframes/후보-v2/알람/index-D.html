알람·비가동 이력 · 시안 D 변형 비교

1차에서 고른 시안 D(왼쪽 요약 열 + 표)를 다섯 가지로 다듬었다. 같은 데모 장면(2026-11-19 14:20). "열기"로 1920×940 실제 크기, "메모 펼침"은 조치 메모 칸이 열린 상태. 왼쪽 목록 · 손볼 건을 누르면 표가 걸러짐.

1차 D에서 바꾼 것 (모두 같음) · 지속 시간 = 보통 굵기 · 보조 글자색, 옆 막대 없앰 · 조치 메모 [쓰기]/[고치기] → 그 행 바로 아래 3줄 입력칸이 펼쳐짐 (취소 · 저장 · Esc, 저장하면 "저장됨" 표시, 담당자 = 로그인 사용자 자동) · 코드는 명세 7개: 알람(고장) 3종 = 장비고장 · 장비고장(알람) · 안전문제, 대기 2 · 정지 2, 0건이어도 늘 보임 · 글자 기호(✓ ✗ ▾ 🔔) → 선 아이콘 · 정지 막대 빗금 → 단색 회색 (impeccable 검사 결과)
