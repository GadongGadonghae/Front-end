생산 조회 · 제품 중심 시안 비교

생산 화면의 주인공은 생산품(제품). 앞 시안 C(제품 추적 먼저)를 출발점으로, 지금 데이터가 주는 제품 정보(제품 ID · 라인 · 투입/완료 · 거친 공정 · 결과 · 공정별 설비/시각/판정/사유)만 써서 보여 주는 방식을 다섯 가지로 나눴다. 같은 데모 장면(2026-11-19 14:20, B라인 프레스 3단 고장 → B라인 제품이 프레스에서 멈춤). "열기"로 1920×940 실제 크기.

공통 규칙 · 결과 = 양품 출고 / 불량 제외(어느 공정) / 진행 중(지금 위치) · 거친 공정 칩: 지남(회색) · 처리 중(파랑 테두리) · 고장으로 멈춤(빨강, 고장 뜻) · 불량 제외 위치(먹색) · 결과 칩에 오늘 수(전체 5,831 · 양품 5,567 · 불량 229 · 진행 중 35) · 계획 대비는 작게 한 줄만 · 값은 데모

G1~G5 디자인 요소 (가동률 시안 G와 같은 원칙: 데이터 뜻만 그림, 빨강 = 고장 하나) · 행 바탕 = 그 제품의 지금 상태 (고장으로 멈춤 옅은 빨강 · 불량 제외 먹색 빗금) · 걸린 시간 막대 = 표준(오늘 양품 중앙값, 데모) 대비, 빠름 파랑 · 느림 먹색, 차이 클수록 진하게 (불량은 비교 안 함) · 결과 도넛 · 투입 흐름 막대 · 시간표 지금 이후 옅은 칸 · 공정 칸 쌓임 막대. 카드마다 "이력 탭"으로 두 번째 탭을 바로 열 수 있음
