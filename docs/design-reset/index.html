4. 다음에 정할 것

바탕 체계 하나 고르기

  • Carbon 쪽: 표·격자·글자 단계가 가장 엄격해 "기업 제품" 인상이 강함. 대신 파랑·Plex·직각을 그대로 쓰면 IBM처럼 보임
  • iX 쪽: 산업용이라 상태 도형·이벤트 목록·KPI 카드가 우리 화면에 바로 맞음. 청록 강조는 상태색과 안 겹침. 한글 글꼴은 따로
  • 섞기: 격자·글자·표는 Carbon, 상태 표시·알람·KPI는 iX

원칙 다시 정하기

  • "빨강 = 고장 하나"(D-106) vs 두 체계의 3~4단 경고 (예지보전 위험을 주황으로?)
  • 가동(R) 초록: 지금처럼 칠할지, iX처럼 정상은 중립·이상만 색으로 할지
  • 상태 표시를 색 칸 + 글자에서 도형 + 글자로 바꿀지
  • 이상 행 바탕 칠 vs 왼쪽 막대·위쪽 띠
  • 메뉴: 위쪽 가로 vs 왼쪽 세로
