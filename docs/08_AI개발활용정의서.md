### 4.2 사람이 채워야 하는 칸 (내가 알 수 없음)

보고서에 쓰려면 아래는 **직접 적어야** 합니다. 제가 추정해 넣으면 근거 없는 숫자가 됩니다.

| 항목 | 채울 내용 | 어떻게 구하나 |
|---|---|---|
| 들인 시간 | 하루 몇 시간 × 5일 | 본인 기록 |
| 비포 기준 | AI 없이 같은 범위를 만든다면 걸릴 기간 (경험 또는 수업 과제 기준) | 본인 판단, 근거를 같이 적을 것 |
| 손으로 고친 비율 | AI 결과 중 그대로 쓴 것 / 고친 것 / 버린 것 | 느낌이라도 범위로 적기 |
| 막힌 곳 | AI가 틀렸거나 헤맨 지점 | 아래 4.3에 제가 아는 것을 적어 뒀으니 보태세요 |
| 배운 것 | 다음에 다르게 할 것 | 본인 |

### 4.3 잘 안 된 것 · 조심한 것 (보고서에 쓰면 신뢰가 올라가는 부분)

- **AI가 스스로 알아본 오류**: 11/20 API 점검에서 "손볼 건 → 보고서 안 만든 고장" 항목을 결함으로 보고했는데, 그 항목은 D-111로 이미 바뀌어 사라진 것이었다. **코드는 맞았고 AI의 기억이 뒤처진 사례** → 이 때문에 결정↔구현 역링크 표(`05_결정_구현대조표.md`)를 만들었다.
- **시안 수치를 구현에 그대로 옮기지 않기**: 시안 HTML의 px·여백을 구현에 복사하지 않는다는 규칙을 사용자가 못 박았고, 기억에 남겼다(`wireframes-are-layout-reference`).
- **AI 티 나는 디자인 걷어내기**: 목록 선택에 왼쪽 진한 띠를 쓰는 흔한 AI 패턴을 사용자가 지적 → 가라앉은 면 + 가는 테두리로 바꾸고 기억에 남겼다(`no-left-accent-bar`).
- **지어내지 않기 규칙**: "명세에 없는 기능·수치·문구를 지어내지 않는다. 데모용 값이 필요하면 그렇다고 밝힌다"를 `CLAUDE.md`에 넣고, 화면에 "데모 데이터" 표시를 띄운다.
- **검사기 오탐도 근거를 남김**: impeccable 탐지기 경고를 끌 때마다 이유를 `.impeccable/config.json`에 적었다 (모눈 배경은 도면 표면에만, 글꼴 스택 오탐 등).

## 6. 다음에 다시 쓸 때 (도구 설정 복제)

이 프로젝트의 AI 설정을 그대로 가져가려면:

1. `.claude/settings.json` — 마켓플레이스 2개(unslop, impeccable)와 켜고 끈 플러그인
2. `.claude/skills/ui-ux-pro-max/` — 저장소에 함께 둔 스킬
3. `CLAUDE.md` — 프로젝트 규칙 (스킬 역할 분담표가 핵심)
4. `.impeccable/config.json` — 탐지기 예외와 그 이유
5. `eslint.config.js` — 층 의존 방향 강제
6. `docs/인터뷰/대조표생성.sh` — 결정↔구현 역링크 다시 만들기

> 교훈 하나: **규칙은 기억이 아니라 저장소에 둔다**. 다른 PC에서 작업하면 기억은 따라오지 않지만 `CLAUDE.md`는 따라온다 (기억 `rules-live-in-claude-md`).
