### 3.3 알아 둘 것

- **데모 데이터**: 지금 화면 값은 모두 프론트 데모 공급기가 만든다. 화면 상단에 "데모 데이터"가 표시된다. 데모는 새 고장을 만들지 않아 고장 토스트가 아직 나타나지 않는다.
- **npm audit 중간 7건**: 모두 개발용 린트 도구(typescript-eslint) 안의 `minimatch`. 빌드 결과물에 들어가지 않는다. 고치려면 옛 버전으로 내려야 해서 보류.
- **시안의 점검 경고**: 시안은 구성 확인용이라 여백 경고 등은 `.impeccable/config.json`에 예외로 등록했다. 실제 화면은 Vue 구현에서 따로 점검한다.
